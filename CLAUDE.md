# Текстовые инструменты (PWA) — правила доработки

- Приложение: `index.html` (интерфейс и ядро), `sw.js` (офлайн-кэш), `help.part` (справка, окно ⋮ → «Справка»).
- Ядро — участок `index.html` между `/*CORE-START*/` и `/*CORE-END*/`: только обработка текста, без DOM (проверяется в node).
- **Справка `help.part`** — при каждом изменении или добавлении функции обновлять нужный раздел. Тест проверяет, что в справке есть все вкладки.
- **Версия:** `APP_VERSION` в `index.html` и `VERSION` в `sw.js` (формат ГГГГ-ММ-ДД.N) увеличивать вместе. Новая версия ждёт нажатия «Обновить» (без авто-skipWaiting). `sw.js` удаляет только свои кэши `text-tools-*`.
- **Перед каждым обновлением — полные проверки:**
  `node tests/core.test.js index.html` и
  `python3 -m http.server 8765`, затем `node tests/ui.test.js http://localhost:8765/index.html <папка снимков> http://localhost:8765/tests/host.html` (нужен Chrome и playwright).
- **Мини-окно поверх всех окон** (Document Picture-in-Picture): интерфейс переносится в документ мини-окна, поэтому код интерфейса обращается к `DOC`/`WIN`, а не к `document`/`window`; обработчики уровня документа и окна подключаются через `docOn`/`winOn`; буфер обмена — `WIN.navigator.clipboard`.
- Название приложения в шапке — обязательно, в том числе на телефоне и в мини-окне. Без анимаций и «въезжающих» экранов.
- Хранилище — только ключ `text-tools-v1` (хранилище общее для всех приложений на mrtekhnik.github.io); чужие ключи (`my-templates-*`, `mrtekhnik.sync`) не трогать.
- Интерфейс на русском; учитывать украинские тексты.
